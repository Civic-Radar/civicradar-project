# SRS-311.1 — View shared officials list (AO)

> **SRS-311.1, AO, View shared officials list.** The system shall display a single shared list of officials extracted from documents for the pilot municipality.
>
> **Acceptance:**
> * Each official appears once in the list.
> * Each entry shows name, title, role, and available contact information.
> * Details that aren't available are labeled as unavailable (consistent with UR-308).
> * Each entry links to at least one source document (consistent with UR-303).
>
> Traces to: UR-311

## What was built

| Task | File | What it does |
|---|---|---|
| 311.1-1 | `app/api/officials/route.ts`, `lib/extractions.ts` | `GET /api/officials` returns the shared list (signed-in users): each official once, with the most recent title, role, email, and phone, the governing body, and every source document |
| 311.1-2 | `app/(app)/officials/page.tsx` | **Officials** page: one card per official, each field next to its label, "Not found" when unavailable, and a "Found in" list linking each source document to its detail page (`/documents/<id>`) |
| 311.1-3 | `app/components/ContactsTabs.tsx`, `app/components/Sidebar.tsx` | The sidebar has one **Contacts** item for this whole area; an **Officials** tab under the page title opens this page |
| 311.1-4 | `__tests__/api/officials-list.test.ts` | 6 tests: each official once, all details, unavailable details empty ("Not found" on the page), every entry linked to at least one source document |

The list is filled by SRS-311.2. Salem is the only town, so the whole list is the pilot municipality's.

## Demo

1. Log in and run two extractions that name the same person, for example:
   - **Joint Public Hearing with the Planning Board Monday October 19, 2026** (agenda): "Maureen Elizabeth Fisher, City Clerk", no contact details.
   - **Salem City Council Special Meeting October 15, 2026** (agenda): "Acting City Clerk", mfisher@salem.com, 978-619-5614.
2. Open **Contacts** in the sidebar, then the **Officials** tab.
3. Maureen Elizabeth Fisher appears **once**, with the newest title and both contact details, and **Found in** lists both documents. *(SRS-311.1 and SRS-311.2.)*

Officials found before this change aren't in the list; only extractions run from now on add to it.
