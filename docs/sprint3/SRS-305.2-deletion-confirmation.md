# SRS-305.2 — Deletion confirmation (AO)

> **SRS-305.2, AO, Deletion confirmation.** The system shall ask the user to confirm deletion, naming the extraction's source document, when the user selects Delete.
>
> **Acceptance:** Given a saved extraction of document X, When the user selects its Delete control, Then a confirmation naming document X is displayed.
>
> Traces to: UR-305

## What was built

| Task | File | What it does |
|---|---|---|
| 305.2-1 | `app/(app)/extractions/page.tsx` | A **Delete** button on each saved extraction |
| 305.2-2 | `app/(app)/extractions/page.tsx`, `lib/extractions.ts` | Selecting it opens a confirmation under that extraction: **Delete your extraction of "&lt;document title&gt;"?** with **Cancel** |
| 305.2-3 | `__tests__/api/deletion-confirmation.test.ts` | 3 tests: the confirmation names document X, names only that document, and comes from the extraction whose Delete was selected |

**Database / API:** none needed to ask for confirmation; the title is already on each saved extraction (`extractions.source_document_title`, from SRS-304.1). The deletion itself is SRS-305.4.

## Demo

1. Open **Saved Extractions**.
2. Click **Delete** on an extraction of document X.
3. A confirmation naming document X appears under it. *(Acceptance criterion.)*
4. **Cancel** closes it and the extraction stays listed.

## Notes
- The Delete control is SRS-305.1 and Cancel is SRS-305.3, which aren't on this sprint's board, but SRS-305.2 can't be shown without them ("when the user selects Delete"), so both are included minimally.
