# SRS-301.8 — Extractable documents (AO)

> **SRS-301.8, AO, Extractable documents.** The system shall list on the extraction page only documents from the user's followed towns whose meeting has already taken place.
>
> **Acceptance:** Given a user follows Salem but not Brookline, and Salem has documents for a meeting that has taken place and for one that has not, When the user opens the extraction page, Then only the documents for the Salem meeting that has taken place are listed.
>
> Traces to: UR-301

## Why
With Brookline added, the extraction page listed every town's documents (Salem and Brookline) regardless of the user's followed towns, and 15 Brookline agendas were for meetings that hadn't happened yet. The Documents page already lists only followed towns (SRS-201.1, MS); this applies the same rule here.

"Taken place" means the meeting's start time has passed. No schema change.

## Demo

1. In **Preferences**, follow **Salem** only.
2. Open **Contacts → Request**: only Salem documents are listed, all for meetings that have already happened. *(Acceptance criterion.)*
3. Follow **Brookline** too: its documents for past meetings appear; its upcoming meetings' agendas don't.
4. Unfollow every town: the page asks you to choose towns in Preferences.

## Notes
- This changes which documents can be picked. A request for a document by its id is not blocked by this rule.
