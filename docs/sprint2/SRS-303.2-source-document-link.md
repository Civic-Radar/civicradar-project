# SRS-303.2 — Source document link (AO)

> **SRS-303.2, AO, Source document link.** The system shall open the source document's detail page (SRS-203.1) when the user selects the source link on an extraction result.
>
> **Acceptance:** Given an extraction result for document X is open, When the user selects the source link, Then document X's detail page opens.
>
> Traces to: UR-303

## What was built

| Task | File | What it does |
|---|---|---|
| 303.2-1 | `app/(app)/extractions/[id]/page.tsx`, `lib/extractions.ts` | The document title at the top of an extraction result is the source link. It opens `/documents/<id>`, the document detail page from SRS-203.1 (MS) |
| 303.2-2 | `__tests__/api/source-document-link.test.ts` | 3 tests: the link for document X goes to `/documents/X`, following it loads document X (not another one), and an extraction without a source document has no link |

The detail page itself (`app/(app)/documents/[id]`) is Marcos's SRS-203.1 and was not changed.

## Demo

1. Log in, open **Contact Extraction**, and open any extraction (or request a new one).
2. At the top, under **Document**, the document's title is shown as a link.
3. Click it. The document's detail page opens (`/documents/<id>`) with the same title. *(This is the acceptance criterion.)*

## Notes
- If the source document is removed from Civic Radar, the extraction keeps its title (`documents` uses `on delete set null`), and the title shows without a link. The "The source document is no longer available." message is SRS-303.3, which is not part of this sprint.
